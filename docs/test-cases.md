# Test cases

## Term extraction

### Required terms

Explained in the following format:
```
- <original sentence>
  - <lemma of term that must appear>
  - <lemma of term that must appear>
  - ...
- ...
```

It's OK if there are *more* terms than that.

- He was surrounded, so gave himself up
  - he
  - be
  - surround
  - so
  - give up
  - himself
- Du siehst müde aus
  - du
  - aussehen
  - müde
- Lo lamentó
  - lo
  - lamentar
- Ein gemeiner Hund
  - ein
  - gemein
  - Hund
